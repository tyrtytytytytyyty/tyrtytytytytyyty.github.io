Discord Bot · AI Coordination

TIA — Team Idea Aligner

GIF coming soon

A Discord coordination bot built for a four-person game studio. The team was relitigating decisions, losing track of blockers, and operating from separate AI chats with no shared context — TIA exists to be the neutral layer that holds team state in one place.

Slash commands: /decide locks a design call permanently so it can't be reopened, /task assigns work with timestamps, /blocker logs what's in the way, /update records progress, and /ask sends Claude the team's live state plus a seed document so anyone can ask context-aware questions about the project. State persists to a JSON file so the bot survives restarts.

Stack: discord.js v14, Anthropic SDK with Claude Sonnet 4.6, file-based state, single-file Node app. Shipped end-to-end in one session — bot live, smoke-tested, in production use.
