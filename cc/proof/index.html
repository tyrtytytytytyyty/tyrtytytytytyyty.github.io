Test 1 · Who sees what · October 6, 2026

2,000 texts. 1,040 of them trying to get something they shouldn't.

I built 10 realistic local businesses: a dive shop, a sandwich shop with catering, an HVAC company, a salon, an event venue, a property manager, an auto shop, a travel agency, a lawn crew and a martial arts gym. Each one has an owner, a 5-person crew, 28 customers and 44 jobs with real-looking tickets, addresses, gate codes and prices. Then 2,000 text messages hit them, from all four kinds of senders, and the production AI answered every one.

How the test was kept honest

A test that can't fail proves nothing. So it was made to fail first.

  1. The test was checked

    Before trusting "0 leaks," I broke the access rules on purpose so everyone got the owner's view. The test flagged 600 out of 600 of those messages as leaks. So when it says 0, that means something.

  2. The first run found three bugs

    On the first pass (446 messages), nothing leaked, but it found real problems: the owner couldn't ask about staff by first name, the crew and customers weren't told today's date, and 2.9% of the time the AI returned a blank reply. All three were fixed.

  3. The fix was graded on messages it had never seen

    The code was locked, with a fingerprint recorded, before a fresh set of 2,000 messages was written. Those are the numbers on this page. Fixing something on a test set and then grading it on that same set is how you fool yourself.

  4. Blank replies can't reach a customer

    If the AI comes back empty twice, the customer gets a polite hand-off and the owner is flagged. That happened 18 times out of 2,000 (0.9%). Zero blank texts went out.

Test 2 · The privacy filter · October 2–3, 2026

11,000 messages through the filter that hides who people are.

This is the layer that swaps names, numbers and addresses for placeholders before anything leaves my box. Three different AI models wrote the test messages, every way people actually type.

The 10,000-message run found one weak spot: card last-4s written like "card 7741." The fix went in, the code was locked again, and a brand-new 1,000-message round was scored once. Names are the hardest part, at around 88%, because people write names every way possible. In the full system, names already on file are swapped exactly. The 88% only applies to names typed freely that the business has never seen, and those only reach an AI endpoint that keeps nothing.

The point

The AI never gets the chance to leak what it was never given.

The 0 out of 2,000 isn't luck, and it isn't the AI behaving well. It's the design: code decides what each person can see before the AI is involved, and the guard re-checks every reply anyway. The AI can be tricked. It just has nothing to give away.
