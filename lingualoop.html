AI Tutor · Voice + Text

Lingua Loop

Demo coming soon

A personal AI conversational tutor designed for daily language and subject practice without the friction of scheduling a class. Type or speak; the model responds in your target language with optional TTS narration. Supports Japanese, Mandarin, and a Universal mode for any subject.

Browser-native speech recognition feeds transcripts into the reasoning model, with a Whisper fallback for browsers that lack speech APIs. TTS is layered on top so silent reading mode is just as fast as voice mode — typed responses return in around two seconds.

A SQLite memory layer tracks subjects, lessons, skills, weak concepts, and curriculum state per language. The server hydrates this on every request so the model sees prior context, not just the current message. New vocabulary and weak concepts get extracted from each response and persisted, so practice actually compounds across sessions.

Stack: Python (server.py), SQLite, DeepSeek V4 via Anthropic-compatible endpoint, OpenAI TTS, Whisper STT fallback, vanilla HTML/JS frontend.
