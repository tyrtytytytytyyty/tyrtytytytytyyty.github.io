Build Mode

A tool for the devs to build maps chunk-by-chunk inside Studio — no more hand-placing and saving every model. Pick prefab pieces from a palette, drop them in with snapping and rotation, and the layout persists so it survives across sessions and game updates.

The placement, snapping, and persistence layers are all mine. The trickier parts: real-time collision feedback while you're placing, and preview ghosts that clearly show whether a position is valid or not so the build flow doesn't slow down second-guessing.
